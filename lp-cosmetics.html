P2 / 共感・業務課題

丁寧に接客していても、情報が分かれると次につながりにくい。

相談、購入、取り置き、問合せ。お客様とのやり取りは、一度の来店だけでは終わりません。

化粧品店では、商品選びの相談、購入商品、取り置き、サンプル、使用後の問合せなど、お客様との接点が何度も生まれます。

P3 / 継続接客の必要性

「買っていただいた後」が見えないと、次の接点をつくりにくい。

再購入時期や使用後の相談を把握できる仕組みが、継続した接客を支えます。

商品を購入した後にも、「そろそろ使い切りそう」「別の商品も試したい」「使い方を確認したい」といった次の接点があります。

けれど購入履歴や使用状況、サンプル後の確認予定が分からなければ、店舗側から適切なタイミングで確認することも難しくなります。

DPROでは購入履歴や使用中商品、再購入目安、サンプル後のフォローなどを確認できます。必要なときに店舗が判断して次の対応へ進めます。

P4 / 全体導線

LINEから相談、店頭接客、その後のフォローまで一本につながる。

お客様側のLINEと、店舗側の管理画面が同じ接客の流れを支えます。

お客様はLINEから会員ページへ入り、商品を見たり、美容相談を予約したり、取り置きや再購入を依頼できます。

来店時は、店舗側がPCやiPadで顧客情報やこれまでの履歴を確認しながら接客。購入やサンプル、相談内容を記録し、その後のフォローや再購入確認へつなげます。

P6 / 商品・取り置き・再購入

商品を探す、取り置く、もう一度買う。LINEから分かりやすく。

お客様が商品を確認しやすく、店舗も依頼内容を把握しやすい仕組みにします。

お客様は商品カタログから商品を探し、商品情報を確認できます。

欲しい商品はLINEから取り置きを依頼でき、以前購入した商品は購入履歴から再購入へ進むこともできます。

店舗側では取り置きの受付、在庫確認、商品確保、受取準備、受取完了まで状態を管理できます。

電話や口頭だけに頼らず、お客様と店舗の双方が内容を確認しやすい流れをつくります。

商品を選んだ後のやり取りまで、LINEと店舗管理でつなげる。
A
商品カタログ・検索商品を見て、必要な商品を探せます。
B
LINEから取り置き受取希望日と商品を指定して依頼できます。
C
購入履歴から再購入以前購入した商品を確認し、再購入へ進めます。
D
店舗側で状態管理受付から受取完了まで、取り置きの状態を管理します。
P7 / フォロー・再購入

売って終わりではなく、使い始めた後までつながる。

再購入の目安やサンプル後の確認など、次の接客を店舗が判断しやすくします。

DPROでは、お客様が現在使っている商品や購入履歴を確認し、再購入時期の目安を管理できます。

店舗からのおすすめ、定期購入の希望、サンプル使用後の確認予定なども、お客様ごとに記録できます。

必要な対応はフォロー予定として確認できるため、「次にいつ、何を確認するか」を店舗側で把握しやすくなります。

自動で一斉に売り込むのではなく、履歴を見ながら店舗が判断して次の接客へつなげる仕組みです。

P8 / 店舗運用

お客様対応と店舗業務を、別々に管理しない。

PC・iPad・店舗設定画面を使い分けながら、日々の業務を確認できます。

PC管理画面では、本日の美容相談、取り置き、顧客情報を確認できます。

接客時はiPadで顧客履歴を見ながら相談・購入・サンプル・フォローを記録。店舗設定では営業時間、スタッフ、商品・在庫、休業日を管理できます。

さらに、問合せ対応やフォロー予定、再購入候補、キャンペーン対象候補も店舗側で確認できます。

営業前にはsystem-checkから主要画面やシステム状態をまとめて確認できます。
