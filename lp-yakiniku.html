P1 / FIRST VIEW

予約も、順番待ちも、テーブルの動きも。焼肉店の営業をひとつにつなぐ。

お客様の予約・当日受付から、呼び出し、着席、退店後の清掃まで。店舗全体で同じ状況を確認できます。

混雑する時間帯ほど、予約客・順番待ち・飛び込みのお客様を見ながら、どの席がいつ空くかまで判断する必要があります。DPROは、お客様向けスマホ画面と、入口受付・スタッフiPad・オーナーPCをつなぎ、来店前から退店後までの流れをまとめて管理。LINE公式運用と業種専用システムを組み合わせ、受付しやすく、お客様にも状況が分かりやすい店舗運営を支えます。

P2 / PROBLEM
現場の課題

予約表だけ見ても、今すぐ案内できる席までは分からない。

予約客と飛び込み客が重なる時間帯ほど、受付担当者の判断が難しくなります。

営業中に同時に見なければならないもの

  • これから来店する予約客
  • 店頭で待っている順番待ち客
  • 現在食事中のテーブル
  • 会計中・清掃中のテーブル
  • 電話や店頭で追加される受付

予約は入っている。店頭には順番待ちのお客様がいる。さらに、食事中・会計中・清掃中のテーブルもある。こうした情報が別々だと、「次に誰を、どの席へ案内するか」をその都度確認しなければなりません。電話や店頭の受付も加わると、営業中の負担はさらに大きくなります。

焼肉店の受付は、予約件数だけでは判断できない。
P3 / JOURNEY
課題から運用へ

お客様が受付した瞬間から、店舗の営業画面へつながる。

予約・順番待ち・到着・着席を、別々の情報として扱わない運用へ。

お客様は日時予約または当日順番受付を行い、店舗側はその情報を入口受付・スタッフiPad・オーナーPCで確認します。来店後は、呼び出し、到着、着席、食事中、会計、退店、清掃へと状態を更新。誰を待たせているのか、どの席が使えるのかを同じ流れの中で追えるようにします。

P4 / FLOW MAP
HTML / CSS 図解

「お客様」「受付」「スタッフ」「テーブル」が、同じ営業の流れで動く。

誰か一人の記憶ではなく、各画面から現在の状況を確認できる仕組みです。

お客様のスマホから入った予約・順番受付を店舗で確認し、入口で到着を受け付け、スタッフが空席へ案内。着席後は会計、退店、清掃へ進め、空席になれば次のお客様へつなげます。P4では、この一連の流れを「来店前 → 受付 → 案内 → 利用 → 清掃 → 次のお客様」という順番で分かりやすく見せます。

P5 / CUSTOMER EXPERIENCE
お客様側

お客様は、「予約する」か「今から並ぶ」かをスマホで選べる。

日時を決めて来店したい方にも、今から行きたい方にも対応します。

日時予約では、人数・コース・席希望を選び、案内可能な時間を確認できます。当日順番受付では、現在の待ち組数や予想待ち時間を確認して受付。受付後は予約や順番の状況を確認し、必要に応じて到着連絡や予約変更・キャンセルも行えます。

予約客にも当日客にも、分かりやすい来店入口を用意できる。

P6 / STAFF OPERATION
スタッフ側

受付した後も、席へ案内して終わりではありません。

呼び出しから退店後の清掃まで、スタッフが卓の状態を更新できます。

スタッフiPadでは、待っているお客様の呼び出し、到着、保留、着席を操作できます。着席後は食事中、会計中、退店、清掃中へ状態を進め、清掃が終われば空席へ戻します。予約客と順番待ち客、現在のテーブル状況を見ながら、次の案内を判断しやすくします。

焼肉店に必要な「席が空くまで」の運用まで管理できる。
P7 / STORE MANAGEMENT
日常管理

毎日の受付だけでなく、店づくりに必要な設定や確認もまとめて。

顧客情報、営業時間、コース、テーブル、営業状況を店舗側で管理できます。

オーナーPCでは、氏名・電話・顧客番号から顧客を検索し、来店回数やアレルギー、内部注意事項を確認できます。営業時間、臨時営業・休業、コース、テーブル、スタッフなどの店舗設定にも対応。さらに、来店人数や待ち時間、テーブル回転などの運用状況を確認できます。

P8 / YAKINIKU FIT
焼肉店専用運用

予約を取るだけではなく、「次に案内できる席」まで考える。

焼肉店では、人数・席種・利用時間・清掃状況まで営業に影響します。

DPROでは、テーブルごとに席種や人数を管理し、使用中・会計中・清掃中・空席といった状態を共有できます。個室や掘りごたつなどの席希望、テーブル結合、利用時間、清掃時間も店舗設定の対象です。単に予約を受け付けるのではなく、実際の店内運用へつなげることを重視しています。

P10 / CLOSING
相談・確認から

まずは、お店の今の受付方法に合うか確認してみませんか。

LINE公式・ホームページ・焼肉店専用DPROシステムを、まとめて運用できます。

DPRO SHOPでは、LINE公式運用3,300円、ホームページ運用1,100円、DPROシステム運用1,100円を合わせて、月額5,500円（税込）で運用します。予約や順番待ち、テーブル管理をすべて一度に変える必要があるかも含め、まずは現在のお店の受付方法や困っていることをLINEで確認してください。実際のDEMOを見ながら相談できます。
